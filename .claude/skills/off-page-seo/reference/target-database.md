# Curated Target-Site Database

Hand-picked, generally high-DA and low-spam off-page targets by category and region. **DA
values are approximate and must be re-verified live** (`metrics-and-vetting.md`) before
presenting — they drift over time. Use this list as the candidate pool; the live vetting
decides what actually gets recommended. Only legitimate, white-hat platforms are listed.

> Approx DA bands: 🟢 80–100 (very high) · 🔵 60–79 (high) · 🟡 40–59 (medium) · ⚪ 20–39 (useful, verify).

### Usage notes
- Always **filter this pool by the chosen task + location**, then **vet live** before
  presenting. Don't dump the whole list at the user.
- The 🟢/🔵 bands are starting hints only — the live DA/PA/spam numbers from the tools are
  the source of truth in the final table.
- Add discovered competitor referring domains to this pool each run; over time the live
  discovery is often higher-value than the static list.
- Drop any site whose live spam score exceeds the user's threshold, even if it's listed here.
